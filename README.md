# Sundered Vale

An original 5v5 fantasy battle arena for Windows.

**Download:** get `SunderedVale_<version>_x64-setup.exe` from the [latest release](../../releases/latest) and run it. After that the game updates itself: new versions install from the main menu or from Settings → About.

The installer isn't code-signed, so Windows may warn about an unknown publisher. Choose **More info → Run anyway**.

This repository only holds the game's releases.
